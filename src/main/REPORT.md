# REPORT — PokéAPI Test Suite

## 1. Выбранный API

**PokéAPI** — https://pokeapi.co/api/v2

Выбран как богатый публичный REST API с множеством эндпоинтов, вложенными объектами,
пагинацией и предсказуемой структурой ответов. Не требует авторизации, что упрощает
написание тестов. Хорошо подходит для отработки навыков тестирования контракта ответа
и граничных случаев.

## 3. Что узнали об API

- **Несуществующий endpoint возвращает 404, а не 400.** Код `400 Bad Request` в PokeAPI
  не используется для неизвестных путей — это важное отличие от ряда других REST API.

- **API принимает нечисловые query параметры без ошибки** — `limit=abc` не вызывает 400,
  сервер просто использует значения по умолчанию и возвращает 200.

- **Экстремальный limit не вызывает ошибку** — `limit=2000000000` возвращает 200
  и отдаёт все доступные ресурсы.

- **Цепочки эволюции не всегда содержат `evolves_to`** — некоторые покемоны (например,
  Mew, id=1 в evolution-chain) не эволюционируют, поэтому `hasSize(greaterThan(0))`
  может упасть на части ID. Это ограничение текущей реализации теста.

- **PokéAPI — read-only API** — метод POST возвращает 405 или 404 в зависимости от
  endpoint, что подтверждает документацию.

## 4. Инструменты

**Основной стек:**
- Java 17
- JUnit 5 (`@Test`, `@ParameterizedTest`, `@ValueSource`, `@Tag`)
- REST Assured — DSL для HTTP-запросов и assertions
- Hamcrest — матчеры для проверки тела ответа
- AssertJ / JUnit Assertions — для проверок извлечённых коллекций

**Что понравилось:**
- REST Assured позволяет писать читаемые тесты в стиле given/when/then
- JsonPath синтаксис (`results[0].name`, `results.size()`) удобен для вложенных структур
- `extract().path()` позволяет работать с ответом как с Java-коллекцией

**Что вызвало затруднения:**
- Вложенные объекты (`chain.evolves_to[0].evolution_details`) требуют знания
  точной структуры ответа — без документации сложно
- Поведение API при граничных значениях (limit, offset) не всегда документировано

## 6. Запуск тестов

```bash
mvn test
```

Запуск только определённой категории через тег:

```bash
mvn test -Dgroups="happy-path-barry"
mvn test -Dgroups="parameters"
mvn test -Dgroups="bad-requests"
```
